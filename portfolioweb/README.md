## Publicar con GitHub Pages

1. Sube todo el contenido de esta carpeta a la raíz del repositorio (`index.html` debe quedar en la raíz).
2. En GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
3. Elige la rama `main` y la carpeta `/ (root)` y pulsa **Save**.
4. En 1–2 minutos la web estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
